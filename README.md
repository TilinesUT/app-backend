# Configuración del Proyecto

Para importar la base de datos automáticamente e instalar todas las dependencias del proyecto (compatible con Windows y Linux), ejecuta el siguiente comando en tu terminal:

```bash
node setup.mjs
```

> **Nota:** El script te solicitará de forma interactiva la contraseña del usuario `root` de MySQL/MariaDB para poder cargar el archivo de la base de datos.
